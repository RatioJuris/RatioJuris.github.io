# ratiojuris.github.io

The RatioJuris portfolio and **Legal Centre**: one place for the privacy policy, terms of use and support page of every product.

## Add or update a product

1. Open [`_data/products.yml`](_data/products.yml).
2. Copy an existing entry and change the values (name, platform, data handled, permissions, network use, FAQ…).
3. Commit and push. GitHub builds and publishes the site in about a minute.

Each product automatically gets:

| Page | URL |
|---|---|
| Overview | `/legal/<slug>/` |
| Privacy Policy | `/legal/<slug>/privacy/` |
| Terms of Use | `/legal/<slug>/terms/` |
| Support | `/legal/<slug>/support/` |

…plus a card on the home page and a row in the Legal Centre.

## Change the wording for every product

| What | File |
|---|---|
| Privacy Policy text | [`_layouts/privacy.html`](_layouts/privacy.html) |
| Terms of Use text | [`_layouts/terms.html`](_layouts/terms.html) |
| Support page | [`_layouts/support.html`](_layouts/support.html) |
| Contact email, governing law | [`_config.yml`](_config.yml) |
| Developers / publishers | [`_data/entities.yml`](_data/entities.yml) |
| Showcased works | [`_data/works.yml`](_data/works.yml) |

When you change the master policy or terms text, update `legal_updated` in `_config.yml`. When you change one product's details, update that product's `updated` date.

## Linking from a product

Point the product's website, app store listing and in-app links to:

```
https://ratiojuris.github.io/legal/<slug>/privacy/
https://ratiojuris.github.io/legal/<slug>/terms/
https://ratiojuris.github.io/legal/<slug>/support/
```

## How it is built

Jekyll 4, built by GitHub Actions ([`.github/workflows/pages.yml`](.github/workflows/pages.yml)). The pages for each product are generated by [`_plugins/legal_pages.rb`](_plugins/legal_pages.rb). No cookies, analytics or external fonts.
